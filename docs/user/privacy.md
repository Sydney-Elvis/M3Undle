# Privacy

This page covers the **documentation website** you are reading, which is
published on GitHub Pages at <https://sydney-elvis.github.io/M3Undle/>. It does
not describe what the M3Undle application itself does on your server.

## Google Analytics, only if you accept

The site uses Google Analytics 4 to count visits, but **only if you accept it**.

- **Your choice comes first.** The first time you visit, a banner asks whether
  Google Analytics may run. Until you accept, the script is not loaded, no
  request goes to Google and no analytics cookie is set. If you reject, none of
  that ever happens. Your choice is remembered in your browser, and **Change
  cookie settings** in the footer of every page lets you change it.
- **What it collects.** The standard page-view and visit data Google Analytics
  gathers: which page was read, roughly when, the browser and device type, an
  approximate location, and where the visitor came from. It sets cookies in your
  browser to tell visits apart.
- **Why.** Only to see which help pages are read and which are ignored, so
  low-value pages can be trimmed or rewritten. There is no advertising and the
  data is not sold.
- **Opting out.** Reject the banner, or use **Change cookie settings** later. A
  content blocker also works. Nothing on this site is needed to run M3Undle.
- **Google's policy.** [policies.google.com/privacy](https://policies.google.com/privacy).

## GitHub

The site is static files on GitHub Pages, so GitHub, which hosts them, sees
visits as any web host does. The repository link in the header can show the
repository's stars and latest release. That is fetched from `api.github.com`,
and only if you accept the cookie banner.
